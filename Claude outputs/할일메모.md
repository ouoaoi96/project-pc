1. **패밀리사이트 연결**
   - 푸터 「Family Site」 선택 목록(select.js)에서 항목을 고르면 해당 사이트로 이동하게 연결
   - 대상 파일: `common/main_footer.html`, `common/sub_footer.html`, `js/select.js`
2. **오시는길 탭**
   - sub1_3(본사) ↔ sub1_3_2(서울사무소) 를 페이지 이동이 아니라 한 페이지 안의 탭으로 전환
   - 대상 파일: `sub1/sub1_3.html`, `sub1/sub1_3_2.html`, `sub1/js/map2.js` (카카오맵)
3. **SNS 연결**
   - 푸터 아이콘 3개(사진 · 영상 · 블로그)에 국순당 SNS 주소 연결 (새 창 열림 + 「새 창」 안내 문구)
   - 대상 파일: `common/main_footer.html`, `common/sub_footer.html`
   - 받은 주소
     - 유튜브(영상 아이콘): https://www.youtube.com/channel/UCQLyL4EyQMXv01PdebmA-WA
     - 인스타그램(사진 아이콘): https://www.instagram.com/kooksoondang/
     - 블로그(글 아이콘): 연결 안 함 — 아이콘만 그대로 둠 (href="#" 유지)

4. **푸터 「개인정보처리방침」 · 「이용약관」 링크**
