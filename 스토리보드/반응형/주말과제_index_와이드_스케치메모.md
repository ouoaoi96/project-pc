# 주말과제 · INDEX 와이드 PC 스케치 메모

- 주제: 월드 오브 워크래프트: 포에버
- 화면: **와이드 PC (1920px 기준, 1280px 넘는 화면)**
- 방식: 종이에 연필 → 펜으로 덧그리기 → 스캔

---

## 0. 그리기 전에

- A4 세로, 틀 너비 **14~15cm** (1920px 비율). 길어서 2단으로 나눠도 됩니다.
- **섹션 하나 = 화면 한 장(100vh)**. 섹션마다 높이를 비슷하게 잡습니다.
- 표시 규칙(모바일 스케치 때와 같음)
  - 사진 · 영상 자리: 박스 + **X**
  - 글 자리: 가로줄 2~3개
  - 버튼: 둥근 사각형 + 글자
  - 움직임 · 클릭: **화살표 + 짧은 메모** (예: "클릭 → 배경 바뀜")
- 각 섹션 오른쪽 여백에 **섹션 이름**과 **쓰는 기술**(Swiper, AOS, grid 등)을 작게 적어 두면 스토리보드에 옮기기 쉽습니다.

---

## 1. HEADER (화면 위에 겹침)

- 왼쪽: `LOGO (WORLD OF WARCRAFT / FOREVER)`
- 가운데~오른쪽: 메뉴 5개 `ABOUT · EXPANSION · CHARACTERS · MEDIA · GALLERY`
- 맨 오른쪽: 버튼 `사전 구매`
- 메모: "투명 → 스크롤하면 검정 배경"

## 2. HERO (풀스크린 영상)

- 화면 전체 박스 + X + `VIDEO (포에버 시네마틱 하이라이트 20초 반복)`
- 가운데 세로로
  - 작은 글씨 `WORLD OF WARCRAFT`
  - 아주 큰 글씨 `FOREVER`
  - `다시 태어난 전설`
  - `2026.11.05 출시`
  - 버튼 2개: `사전 구매` / 동그라미 `▶ 트레일러`
- 아래쪽: 영상 탭 3개 `01 제프라스 섬 · 02 강물터 · 03 하이잘 산`
- 맨 아래 가운데: `SCROLL` + 세로선
- 왼쪽 가장자리: 마름모 점 5개(섹션 위치 표시)
- 메모
  - "트레일러 버튼 → 유튜브 4분 팝업(magnific-popup)"
  - "탭 클릭 → 영상 바뀜"
  - "네 모서리 금색 꺾쇠 프레임"

## 3. 01 ABOUT (풀스크린 원화 + 가운데 정렬)

- 배경 전체 박스 + X `원화(어둡게)`
- 가운데에 아주 큰 테두리 글씨 `AZEROTH` (속이 빈 글씨로 그리기)
- 그 위에 제목 `길들여지지 않은 아제로스가 여러분을 기다립니다`
- 글 2줄
- 장식선 `── ◆ ──`
- 숫자 4칸 (칸 사이 세로선)
  - `1000+ 신규 퀘스트`
  - `3 새 지역`
  - `NEW 스카이본`
  - `ALL 직업 개편`
- 메모: "숫자 올라가는 효과(카운트)", "AOS fade-up"

## 4. 02 EXPANSION (배경 전환형)

- 배경 전체 박스 + X `선택한 확장팩 원화`
- 왼쪽 글 영역
  - 흐린 큰 숫자 `2026`
  - 큰 제목 `FOREVER`, 아래 `월드 오브 워크래프트: 포에버`
  - 글 2줄
  - 작은 태그 3개 `제프라스 섬 · 강물터 · 하이잘 산`
  - 버튼 `자세히 보기` / `▶ 트레일러`
- 아래쪽: 썸네일 4칸 가로 (첫 칸만 크게 · 테두리 진하게)
  - `FOREVER 2026` / `한밤` / `내부 전쟁` / `용군단`
- 메모: "썸네일 클릭 → 배경 · 글 바뀜(jQuery 클래스)", "선택 안 된 칸 흑백"

## 5. 03 CHARACTERS (캐릭터 선택 화면)

- 왼쪽 절반: 큰 세로 박스 + X `캐릭터 원화(스카이본)`. 오른쪽으로 갈수록 흐려지게 빗금
- 오른쪽 글 영역
  - 탭 2개 `얼라이언스 / 호드`
  - 큰 이름 `SKYBORN`, 아래 `스카이본`
  - 글 3줄
  - 작은 칸 `호드: 바람구체자 / 얼라이언스: 고등 마법원`
  - 아이콘 6개 가로 (첫 칸 진하게)
- 메모: "아이콘 클릭 → 캐릭터 그림 · 글 바뀜", "캐릭터 왼쪽에서 슬라이드 등장"

## 6. 04 MEDIA (극장형 영상)

- 위 가운데 제목 `CINEMATIC`
- 가운데 큰 16:9 박스 + X + 가운데 ▶ + 왼쪽 아래 `포에버 시네마틱 트레일러`
- 아래 썸네일 5칸 가로 (첫 칸 진하게)
- 메모: "썸네일 클릭 → 큰 화면 바뀜", "▶ → 유튜브 팝업"

## 7. SOUNDTRACK (사운드)

- 왼쪽: 정사각형 앨범 박스 + X, 오른쪽으로 동그라미(LP판) 반쯤 겹쳐서 삐져나오게
- 오른쪽
  - 제목 `MUSIC OF AZEROTH`
  - 곡 목록 4줄 (`01 ▶ 곡 이름 ··· 03:42`, 첫 줄 진하게)
  - 맨 아래 진행 막대
- 메모: "재생 시 LP 회전(CSS animation)", "`<audio>` 태그"

## 8. 05 GALLERY (grid-areas 갤러리)

- 위 제목 `GALLERY`
- 가로 4칸 · 세로 3줄 grid. 수업 연습(`04.grid_이미지유동`)과 같은 배치
  - `a a b c`
  - `a a d e`
  - `f g h h`
- 칸마다 X + 아래 글 띠
- 메모: "hover → 확대 + 글 띠 올라옴", "클릭 → 크게 보기 팝업", "더 보기 → 서브 masonry"

- 왼쪽: 로고, 출처 문구 `이미지 · 영상 출처 Blizzard Entertainment`
